Native editors use their own file engines and available memory. Complex or very large documents may still exceed an editor’s resources. PDF Tools supports up to 2 GB and 2,000 pages per PDF for many operations; translation and structured extraction have smaller limits shown in those tools.

Your accounts

Gemini now uses Google’s official Antigravity helper. One-time setup downloads about 120 MB from Google and needs about 220 MB of disk space. Google offers free account usage with limits; account eligibility applies. No API key is needed. The helper is downloaded separately under Google’s terms.

ChatGPT and Drive tokens use Windows protected storage. Google’s Antigravity helper and the official Claude helper manage their own login in separate personal app folders. Google’s Windows helper uses a local credential file; protect your Windows account and exclude personal app data from sharing. Connections are never included in the shareable installer.

Writing assistant

Paste only the text you want to send. The assistant does not read open documents or control your computer. Each request is separate.

Stay within free or included usage: set AI Credit Overages to Never in Google Antigravity, and leave paid extra usage disabled in ChatGPT and Claude. AE Studio asks before each request and cannot check your account’s remaining allowance. It never purchases a plan or silently switches to API billing.
